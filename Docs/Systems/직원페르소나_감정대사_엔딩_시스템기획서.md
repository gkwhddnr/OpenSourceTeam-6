## 1. 목적과 검증할 경험

플레이어가 내린 업무 지시 이력(**업무 배분 · 강제 전환 · 음성 발화 말투 · 사장 직접 계산 개입**)이 단순 숫자로만 끝나지 않고, **직원의 실시간 말투·태도 변화**와 **일차별 상태 결산 및 7일차 최종 멀티 엔딩(매장 결말 × 직원 후일담)**으로 되돌아오는 핵심 서사 경험을 정의한다.

본 기획서는 다음 네 가지를 함께 해결한다.
1. **`0일차` 알바 사전 설정 호환 구조**: 특정 캐릭터 1명에 고정하지 않고, 오픈 준비 단계(`0일차`)에서 플레이어가 알바 페르소나를 직접 설정·프리셋 선택·랜덤 생성하더라도 대사와 엔딩이 자연스럽게 출력되도록 템플릿화한다.
2. **음성 발화 태도 및 사장 개입 반영**: 어떤 업무를 시켰는지뿐 아니라 **마이크로 어떻게 말했는지(정중/중립/재촉/폭언)**와 **사장이 직접 계산에 개입했는지**에 따라 감정 수치가 다르게 반응하게 한다.
3. **플레이어 체감 피드백 강화**: 같은 `계산`·`진열` 명령이라도 감정 구간(`안정` / `피로·불만` / `분노·임계`)에 따라 대사 톤이 확연히 달라져 직원의 한계치를 직관적으로 느끼게 한다.
4. **AI 행동 오판 방지(Gating) 및 폭주 엔딩 기준**: 성실·안정 상태에서 극단적인 일탈 코드가 잘못 선택되지 않도록 **감정·충성도 구간별 허용 행동 등급 기준**과 **알바 폭주(중도 이탈) 발동 조건**을 명확히 정의한다.

## 2. 개발 범위 구분 (1차 통합 데모 → 2차 본편 완전체)

| 구분 | 1차 통합 데모 (단일 일차 코어 검증) | 2차 본편 완전체 (`0일차 ~ 7일차` 루프) |
| :--- | :--- | :--- |
| **직원 페르소나** | 대표 프리셋 1명(`김민수` · 현실파 성실형) 기본 적용 | **`0일차` 알바 설정 화면**: 프리셋 3종 + 이름·성격·말투·민감도 직접 설정 + 랜덤 생성 |
| **감정 변화 요인** | 근무/휴식 시간, 작업 중 강제 전환, 거부 시 충성도 하락 | **+ 음성 발화 말투(4단계)**, **사장 직접 계산 개입 반응**, 정산 정비 시 **케어(보너스·간식)** 회복 |
| **감정 대사 출력** | 하단 피드백 배너 + 알바 머리 위 말풍선(`PF_EmployeeWorldStatusUI`) | 말투 스타일(`예의 바름 / 시니컬 / 소심함`) 템플릿 및 `{직원명}` 치환 대사 확장 |
| **일차 결산 · 엔딩** | 1일차 정산 결과 3등급 화면 | 매 일차 마감 **알바 상태 리포트 화면** + **7일차 최종 4대 멀티 엔딩(및 중도 폭주 엔딩)** |

## 3. `0일차` 직원 페르소나 설정 구조 및 기본 프리셋

### 3.1 사전 설정 데이터 구조 (`EmployeePersonaProfile`)
`0일차`(튜토리얼 및 오픈 준비 단계)에서 플레이어는 아래 항목을 설정할 수 있다. 공정한 게임 밸런스를 위해 **허용 업무 종류와 정산 공식(단가·목표 금액)은 모든 페르소나가 동일**하며, 대화 톤과 감정 반응 가중치만 달라진다.

| 필드명 | 설정 방식 | 역할 및 연동처 |
| :--- | :--- | :--- |
| **`EmployeeName`** | 직접 입력 / 랜덤 | HUD 카드, 머리 위 이름표, 후일담 본문의 `{직원명}` 치환 변수 |
| **`PersonalityPrompt`** | 한 줄 설명 입력 / 프리셋 | 이승재 담당 로컬 LLM 시스템 프롬프트에 주입할 성격 문장 |
| **`SpeechStyle`** | `예의 바름(Polite)` / `시니컬(Cynical)` / `소심함(Timid)` | 상황별 반응 대사 및 후일담 문장 템플릿 세트 선택 키 |
| **`Diligence` / `Laziness`** | `0 ~ 100` 범위 내 슬라이더 또는 프리셋 | `EmotionReactionRules` 정상 수락 vs 태만(농땡이) 확률 보정 |
| **`StressSensitivity`** | `둔감(0.85x)` / `보통(1.0x)` / `예민(1.25x)` | 업무·재촉·진상 이벤트 발생 시 스트레스 상승 배율 |

### 3.2 대표 기본 프리셋 3종 (1차 데모 기본값: `EMP_01 김민수`)

| 프리셋 ID | 이름 · 콘셉트 | 말투 / 민감도 | 초기 스탯 (`스트레스 / 피로 / 충성`) | 특징 요약 |
| :--- | :--- | :---: | :---: | :--- |
| **`EMP_01` (기본)** | **김민수** (현실파 성실형 휴학생) | `예의 바름` / `보통(1.0x)` | `25 / 15 / 70` | 평소엔 군말 없이 `"네, 사장님!"` 하고 일하지만 임계점(`80+`)에서 웃음기 뺀 차가운 존댓말 정색으로 거부함 |
| **`EMP_02`** | **박서연** (시니컬 3년 차 경력직) | `시니컬` / `둔감(0.85x)` | `20 / 15 / 60` | 처음부터 말투는 툴툴대지만 스트레스 내성이 좋음. 단, 비효율적 강제 업무 전환 시 충성도가 `1.5배` 크게 깎임 |
| **`EMP_03`** | **이도윤** (의욕 과다 유리멘탈 초보) | `소심함` / `예민(1.25x)` | `30 / 10 / 85` | 충성도는 높게 시작하지만 재촉·폭언·진상 손님에 스트레스가 빠르게 치솟으며 당황 실수가 잦음 |

## 4. 감정 스탯 3종 · 음성 말투 · 사장 개입 연동 규칙

### 4.1 3종 스탯의 역할 및 기본 변화 조건
| 스탯 (`0~100`) | 기획상 의미 | 주요 상승(+) 조건 | 주요 하락(-) 조건 | 직접 영향을 주는 곳 |
| :--- | :--- | :--- | :--- | :--- |
| **스트레스** | **단기 감정 폭발치** | 업무 수행 중 지속 상승, 작업 중 강제 전환(`+12`), 재촉/폭언 발화, 진상 응대 | `휴식/대기(Rest)` 유지 중 회복, 정산 정비 시 케어(간식·보너스) 소비 | 실시간 작업 효율(`1.0/0.8/0.5`), 반응 확률, **폭주 엔딩 트리거** |
| **피로도** | **누적 체력 소모치** | 업무 수행 및 기상 악화일 근무 중 누적 | `휴식/대기` 중 완만 감소, 일차 전환 시 기본 수면 회복 | 피로도 `70` 이상 시 스트레스 상승량 및 태만(`SLACK_OFF`) 확률 가중 |
| **충성도** | **사장에 대한 신뢰도** | 정중한 지시, 작업 완수, 정산 시 보너스 지급 | 강제 전환 반복, 폭언 지시, 분노 상태 지시 강행·거부(`-5~-8`) | 고스트레스 구간 거부율 증폭, **7일차 최종 엔딩 분기 핵심 지표** |

### 4.2 플레이어 음성 발화 태도(말투)에 따른 차등 보정 (본편 음성 연동 핵심)
같은 `"계산대 봐"` 지시라도 **플레이어가 마이크로 말한 어조·단어 선택**을 판별(`Polite / Neutral / Pressuring / Hostile`)하여 즉시 감정에 반영한다.

| 발화 태도 분류 | 실제 발화 예시 | 즉시 감정 변화 (기본값) | 페르소나 연동 효과 |
| :--- | :--- | :--- | :--- |
| **정중 · 격려 (`Polite`)** | *"민수 씨, 계산대 좀 부탁해요"*, *"고생했어, 잠깐 쉬어"* | 스트레스 **`-4`**, 충성도 **`+3`** | 성실형·소심형에서 충성도 회복 효율 상승 |
| **일반 · 중립 (`Neutral`)** | *"계산해"*, *"진열대 채워"* | 추가 보정 **`0`** *(기본 업무 증감만 적용)* | 모든 페르소나 동일 |
| **재촉 · 압박 (`Pressuring`)** | *"빨리 계산 안 해?"*, *"왜 이렇게 느려, 당장 가!"* | 스트레스 **`+8`**, 충성도 **`-3`** | 예민(`1.25x`) 페르소나는 스트레스 `+10` 상승 |
| **폭언 · 비난 (`Hostile`)** | *"일 똑바로 못 해?"*, *"돈 날로 먹네"* | 스트레스 **`+18`**, 충성도 **`-10`** | 시니컬·자존심 강한 페르소나는 즉시 거부 확률 급증 |

### 4.3 플레이어(사장) 직접 계산 개입 시 알바 감정 반응
본편에서 손님 NPC를 알바 대신 **사장이 직접 계산**할 경우, 인건비(건당 수당)를 아끼는 대신 알바 상태에 따라 아래 감정 변화가 발생한다.
- **알바가 `안정(0~39)` 상태일 때 사장이 연속 직접 계산**: 성실형은 *"저를 못 믿으시나…"* 하고 눈치를 보며 `스트레스 +3 / 충성도 -2`, 게으른 성향은 요령이 생겨 이후 `태만` 가중치 소폭 상승 *(사장 독박 계산 꼼수 방지)*.
- **알바가 `분노·과부하(80~100)` 상태이거나 바쁜 피크타임일 때 사장이 보조 계산**: 급한 불을 같이 꺼준 것으로 인식해 알바의 추가 스트레스 누적을 방어함.

### 4.4 LLM 행동 코드 오판 방지용 등급 제한(Gating) 규칙
| 행동 등급 | 포함 행동 예시 | 허용(해금) 조건 | 비고 |
| :--- | :--- | :--- | :--- |
| **Grade 1: 정상 업무** | `ACCEPT_NORMAL` (`Checkout`, `Restock`, `Clean`, `Rest`) | **상시 허용** | 안정 구간 주력 행동 (`Rest`는 전 구간 100% 수락) |
| **Grade 2: 불만·소극 태업** | `ACCEPT_COMPLAIN`, `SLACK_OFF`(농땡이) | `스트레스 ≥ 40` 또는 `피로도 ≥ 60` | 불만 대사 출력, 효율 `0.8x` 또는 대기 이탈 |
| **Grade 3: 정면 지시 거부** | `REFUSE_EMOTION` | `스트레스 ≥ 80` 또는 `충성도 ≤ 25` | 붉은 거부 배너 + 거부 카운트 `+1` |
| **Grade 4: 이상행동 · 폭주** | 물품 파손(`MISTAKE_DROP`), 오결제, **중도 추노(폭주)** | 이상행동: 2차 일차 해금 후 고스트레스<br>**폭주 퇴사**: `스트레스 == 100`이 일정 시간 지속 **&** `충성도 ≤ 15` | 1차 데모에서는 비활성화, 본편에서 **엔딩 4(알바 폭주)** 트리거로 사용 |

## 5. 상황 × 감정 단계별 실전 대사집 (`예의 바름` 기본 템플릿 기준)

하단 피드백 배너 및 3D 알바 머리 위 말풍선(`EmployeeWorldStatusPresenter`)에서 출력하는 대사 레퍼토리다.

| 발화 상황 | 안정 (`스트레스 0~39`) | 피로·불만 (`스트레스 40~79`) | 분노·임계 (`스트레스 80~100`) |
| :--- | :--- | :--- | :--- |
| **계산(`Checkout`) 수락** | `"네, 사장님! 계산대 바로 보겠습니다."` | `"하아… 네, 계산대 갈게요, 가요."` | `"…알겠습니다. 계산만 하면 되는 거죠?"` |
| **진열(`Restock`) 수락** | `"넵, 매대 빈 곳부터 얼른 채워둘게요!"` | `"네에… 허리 끊어지겠네 진짜… 진열하러 갑니다."` | `"네, 채웁니다. 채운다고요."` |
| **작업 중 강제 전환** | `"앗, 하던 거 멈추고 저쪽부터 할까요? 알겠습니다!"` | `"아니 방금 이거 시키셨잖아요… 네, 일단 바꿀게요."` | `"사장님, 진짜 이러기예요? 하던 건 끝내게 해주셔야죠!"` |
| **① 단순 오인식 / 미지원** | `"죄송해요 사장님, 잘 못 들었어요! 다시 말씀해 주시겠어요?"` | `"네? 무슨 말씀이신지… 정확히 다시 말씀해 주세요."` | `"뭔 말씀이신지 모르겠고, 할 말만 딱 해주시면 안 될까요?"` |
| **② 감정 악화 거부 / 태만** | *(태만 극소 확률)* `"잠깐 숨만 고르고 갈게요…"` | `"아 몰라요, 다리 아파서 잠깐만 쉴래요…"` | `"사장님, 저도 손이 두 개거든요? 지금 못 가요."` |
| **휴식(`Rest`) 전환** | `"네! 잠깐 대기하고 있겠습니다."` | `"휴, 살았다… 잠깐만 숨 좀 돌릴게요."` | `"진작 좀 쉬게 해주시지… 저 건드리지 마세요 잠깐."` |

## 6. 일차별 알바 상태 결산 및 최종 멀티 엔딩 분기

전체 게임 흐름([전체_게임흐름_및_일차루프_기획서.md](전체_게임흐름_및_일차루프_기획서.md))에 맞춰 **매 일차 마감 상태 화면**과 **`7일차` 최종 엔딩(및 중도 폭주 엔딩)**을 다음과 같이 연결한다.

### 6.1 매 일차 종료 시 화면 흐름 (`Day 1 ~ Day 7`)
```text
[일차 영업 종료 (시간 만료 또는 조기 마감)]
      │
      ▼
[화면 1: 당일 매출·지출 정산]   ◀── 오늘 매출 - 지출(원가·고정비·알바 수당) 및 목표 금액 달성도 표시
      │  (클릭 / 다음 버튼)
      ▼
[화면 2: 알바 상태 리포트]      ◀── 현재 스트레스 · 충성도 · 감정 등급 · 오늘 퇴근 한마디 출력
      │  (클릭 / 다음 버튼)
      ├─ (Day 1~6 진행 중) ──▶ [화면 3: 정비 및 자금 소비 (발주·알바 케어)] ──▶ 다음 일차(x+1일차) 오픈
      └─ (Day 7 종료 시)   ──▶ [최종 멀티 엔딩 컷신 + 알바 개인 후일담 출력]
```

### 6.2 최종 엔딩 4대 분기 + 알바 개인 후일담 매칭

| 엔딩 코드 | 판정 조건 | 매장(사장) 본편 엔딩 연출 | 연결되는 알바 후일담 (`{직원명}` 치환) |
| :--- | :--- | :--- | :--- |
| **`ENDING_01`<br>(완벽한 동업 · 진 엔딩)** | `7일차 목표 금액 달성`<br>**AND** `알바 긍정`(`충성도 ≥ 70` & `종료 스트레스 < 60`) | **목표 달성 성공 컷신**<br>- 1안(현실): 사채 빚 전액 상환 & 사채업자 통쾌한 참교육<br>- 2안(우주): 은하계 무역 1짱 거상 등극 | **`EPILOGUE_ACE` 「든든한 에이스 파트너의 탄생」**<br>퇴근길 기분 좋게 캔커피를 딴 `{직원명}`은 친구에게 *"우리 사장님 일 배분 진짜 깔끔함"*이라고 카톡을 보냈다. 다음 주부터 `{직원명}`은 매장 매니저 명찰을 달고 출근한다. |
| **`ENDING_02`<br>(피도 눈물도 없는 흑자)** | `7일차 목표 금액 달성`<br>**AND** `알바 부정`(`충성도 < 70` 또는 `스트레스 ≥ 60` 또는 `거부 누적 ≥ 3회`) | **목표 달성(고독한 성공) 컷신**<br>- 돈은 다 벌어 목표를 이뤘지만 텅 빈 카운터에 사장 혼자 남겨짐 | **`EPILOGUE_EXPOSE` 「익명 게시판 인기글과 손절」**<br>마지막 정산금을 입금받자마자 `{직원명}`은 사장 번호를 차단하고 익명 게시판에 *『7일 동안 사람 갈아 넣은 사장 후기.txt』*를 올려 실시간 인기글 1위를 달성했다. |
| **`ENDING_03`<br>(목표 미달 · 폐업 실패)** | `7일차 종료 시 목표 금액 미달`<br>*(또는 중도 자금 완전 파산)* | **목표 미달 배드엔딩 컷신**<br>- 1안(현실): 점포 압류 딱지 & 웃픈 야반도주 엔딩<br>- 2안(우주): 우주 정거장 빈털터리 노숙자 전락 | **`EPILOGUE_LEAVE` 「씁쓸한 마지막 퇴근길」**<br>불 꺼진 간판을 돌아본 `{직원명}`은 구인 앱을 켜며 중얼거렸다. *"사장님도 나쁜 분은 아니었는데… 장사는 아무나 하는 게 아니구나."* |
| **`ENDING_04`<br>(알바 멘탈 폭주 · 중도 실패)** | 영업 도중 `스트레스 100` 지속<br>**AND** `충성도 ≤ 15` 도달 (폭주 이탈) | **영업 중도 파국 엔딩 컷신**<br>- 알바가 앞치마를 카운터에 던지고 실시간 탈주하여 영업 강제 종료 | **`EPILOGUE_RAGEQUIT` 「읽씹과 추노, 노동청 즐겨찾기」**<br>전화를 걸어봤지만 이미 없는 번호였다. 같은 시각 집으로 돌아간 `{직원명}`의 노트북 즐겨찾기에는 '고용노동부 민원마당'이 조용히 추가되어 있었다. |

> **1차 통합 데모(`1일차` 단독 시연) 호환 규칙**: 1차 데모에서는 `7일차` 누적 대신 `1일차 목표 잔액(80,000원)` 달성 여부와 당일 종료 스트레스·거부 횟수로 위 분기 축소판(`안정 성공` / `불안정 분노 성공` / `목표 미달 실패` + 후일담 카드)을 즉시 검증할 수 있다.

## 7. 완료 기준과 검증 방법

1. `0일차`에서 변경한 `{직원명}`과 성향 프리셋이 인게임 HUD, 머리 위 월드 UI, 반응 확률, 최종 후일담 텍스트에 일관되게 반영된다.
2. 동일 업무 지시라도 발화 태도(`정중` vs `폭언`)와 강제 업무 전환 여부에 따라 스트레스·충성도 변화 폭과 출력 대사가 명확히 달라진다.
3. `7일차`(또는 1차 데모 종료) 시점에서 **목표 금액 완수 여부 × 알바 감정 상태** 조합에 따라 `ENDING_01 ~ 03`이 정확히 나뉘며, 극단적 혹사 방치 시 `ENDING_04(폭주 중도 종료)`가 발동한다.
