## 1. 문서 목적 및 개발 단계 구분

본 문서는 게임 최초 실행부터 `0일차(오픈 준비)` → `1~7일차(영업·정산 반복)` → `최종 멀티 엔딩`까지 이어지는 **본편 전체 게임 흐름**과 **스토리·에셋 방향성 후보(기승전결)**를 팀원 전체가 동일한 그림으로 공유하기 위해 작성되었다.

| 구분 | 1차 통합 데모 (단일 일차 코어 검증) | 2차 본편 완전체 (전체 게임 흐름) |
| :--- | :--- | :--- |
| **진행 일차** | 로비 → `1일차` 즉시 진입 (`120초` 시연 기준) | 인트로 → 로비 → `0일차(설정·튜토리얼)` → `1~7일차` 누적 루프 |
| **알바 설정** | 기본 대표 프리셋(`김민수`) 1명 고정 | `0일차`에 프리셋 선택 / 이름·성향 직접 설정 / 랜덤 생성 지원 |
| **손님 · 매출** | 시간 × 감정 효율 비례 가상 매출 (`직원 외 NPC 보류` 규칙 준수) | 손님 NPC 입장 → 물품 선택 → 알바(건수 누적)/사장 직접 계산 → 퇴장 |
| **방해 · 미션** | 없음 (계산·진열·휴식 및 감정 반응 검증 집중) | 일차별 기상 악화·진상 이벤트·알바 이상행동·청소·발주 미션 점진 추가 |
| **정산 · 소비** | 1단 정산 결과창 (매출·원가·고정비·3등급 확인) | 영수증 매출 정산 → 알바 클립보드 상태 확인 및 자금 소비(발주·케어) |
| **엔딩 구성** | 1일차 운영 3등급 (및 2단 후일담 프로토타입) | 7일차 최종 4대 멀티 엔딩(목표×알바 상태) + 중도 파산·알바 폭주 엔딩 |

## 2. 전체 게임 진행 흐름도 (End-to-End Flow)

```text
[게임 최초 실행]
   └──▶ [인트로 연출] (세계관 도입 영상 또는 스토리 텍스트 / 클릭·Esc 스킵 지원)
            │
            ▼
      [메인 로비 화면] (도로변 편의점 외관 & 담배 피우는 캐릭터 / 우상단 ♪ 브금 on·off)
       ├─ [게임 시작] ──▶ (새 게임 시) [0일차: 오픈 준비 단계]
       │                     ├─ ① 알바 채용 클립보드 (프리셋 / 직접 입력 / 랜덤)
       │                     ├─ ② 기본 조작 및 음성 지시 튜토리얼 (스킵 가능)
       │                     └─ ③ 초기 운영 자금(a원) 지급 ──▶ [1일차 오픈 전환 컷신]
       ├─ [설정] ──────▶ [환경 설정 팝업] (4개 상단 탭 · 스크롤 · 초기화/저장/나가기)
       └─ [종료] ──────▶ 게임 종료
                                    │
                                    ▼
  ┌─────────────────── [Day 1 ~ Day 7 일차 반복 루프] ───────────────────┐
  │                                                                      │
  │  1. [인게임 영업 (1인칭 시점)]                                       │
  │     - 상단 HUD: 좌측(X일차) · 중앙(남은 시간) · 우측(목표/현재 금액) │
  │     - 우측 카드: 알바 이름·스트레스 등 상태 / 중앙: + 조준점·월드UI  │
  │     - 하단 중앙: 🎙 마이크 토글 아이콘 + [입력 텍스트 / 피드백 바]   │
  │     - 손님 입장 및 상품 선택 → 알바 음성 지시(또는 사장 비상 계산)   │
  │     - 일차별 방해 효과(기상·진상·알바 이상행동) 및 추가 미션(청소 등)│
  │                                                                      │
  │  2. [영업 종료 트리거]                                               │
  │     - 제한 시간 만료(00:00) 또는 플레이어의 [임의 조기 마감]         │
  │     - (예외: 영업 중 알바 멘탈 완전 폭주 시 → 중도 배드엔딩 직행)    │
  │                                                                      │
  │  3. [일차 정산 및 정비 (영수증 → 클립보드 전환)]                     │
  │     - [화면 1: 영수증] 목표 금액 · 현재 금액 · 오늘 매출 및 지출 내역│
  │     - [화면 2: 클립보드] 알바 사진·상태·스트레스 지수 확인           │
  │        + 보유 자금 소비(내일 물품 발주 · 알바 멘탈 케어)             │
  │        └─ [다음 일차 시작하기 →] 클릭 시 x+1일차 오픈으로 이동 ──────┘
  │        └─ Day 7 종료 (또는 중도 파산) 시: 최종 엔딩 판정으로 이동
  ▼
[최종 엔딩 컷신 및 알바 후일담 출력] ──▶ [메인 로비 복귀]
```

## 3. 단계별 상세 규칙

### 3.1 인트로 · 로비 · 설정 팝업
1. **인트로**: 최초 실행 시 왜 7일 안에 목표 금액을 모아야 하는지 도입 스토리를 출력하며, `[Skip]`을 상시 제공한다.
2. **로비 및 설정 팝업**:
   - 로비 우측 상단에 `♪ 브금 on/off` 토글을 두어 즉시 음소거할 수 있게 한다.
   - 로비에서 `[설정]` 클릭 시 또는 인게임 중 `Esc` 입력 시 **4개 탭 구조의 설정창 팝업**(`초기화` / `저장` / `나가기`, 인게임 진입 시 `로비로 이동` 포함)이 출력된다.

### 3.2 `0일차` (알바 설정 · 튜토리얼 · 초기 자금 지급)
1. **알바 페르소나 설정**: 클립보드(채용 이력서) 화면에서 `이름`, `성격 성향`, `말투 스타일`을 설정한다 (프리셋 3종 / 직접 입력 / 랜덤). **허용 업무와 정산 공식은 모든 페르소나가 동일**하다.
2. **오픈 리허설(튜토리얼) 및 초기 자금 지급**: 마이크 발화와 `Tab` 텍스트 입력을 짧게 연습하고, 기본 자금 `a원`을 지급받은 뒤 1일차 오픈 컷신으로 넘어간다.

### 3.3 인게임 영업: 손님 응대 · 음성 지시 · 사장 직접 계산
1. **음성 명령 및 말투 영향**: 하단 마이크 토글(또는 단축키)로 업무를 지시하며, **강제 업무 전환 여부**와 **발화 말투(정중 / 중립 / 재촉 / 폭언)**에 따라 알바의 스트레스·충성도가 실시간 변화한다.
2. **손님 NPC 흐름 및 계산 주체별 차등 규칙**:
   - 손님 NPC 입장 → 확률에 따라 구매 물품 선택 → 카운터 계산 → 퇴장.
   - **알바가 계산할 경우**: 내부에서 **계산 횟수**를 저장했다가 정산 때 **기본급 + 건당 수당**으로 지불한다.
   - **사장(플레이어)이 직접 계산할 경우**: 건당 수당은 아끼지만 사장 계산 속도가 느려 동선 손해가 발생하며, 알바가 멀쩡할 때 사장이 카운터를 독점하면 눈치·불신(`충성도 하락·스트레스 소폭 상승`), 알바가 분노 과부하일 때 도와주면 부담 완화로 작동한다 *(사장 독박 계산 꼼수 방지)*.
3. **시간 종료 및 임의 조기 마감**: 시간이 다 되거나 플레이어가 임의로 일차를 끝낼 수 있다 (단, 최소 경과 시간 이후 가능, 돌발 사건 수습 전 마감 불가, 일일 고정 운영비는 동일 차감).

### 3.4 일차 마감 정산 (`영수증` → `클립보드`)
1. **[화면 1 — 영수증 정산서]**: 목표 금액, 현재 최종 금액, 당일 매출 및 지출(원가·운영비·알바 수당) 내역을 영수증 형태로 보여주고 `[다음 →]` 버튼을 누른다.
2. **[화면 2 — 알바 클립보드 & 자금 소비]**: 알바 프로필 사진, 이름, 감정 상태, 스트레스 지수를 출력하고, 하단에서 보유 자금을 소비해 **물품 발주 / 알바 멘탈 케어**를 진행한 뒤 `[다음 일차 시작하기 →]`로 넘어간다.

## 4. `0일차 ~ 7일차` 난이도 곡선 및 방해·미션 구성

| 일차 | 핵심 목표 및 해금 요소 | 방해 효과 · 추가 미션 | 난이도 의도 |
| :---: | :--- | :--- | :--- |
| **`0일차`** | 알바 페르소나 설정 + 음성/텍스트 지시 튜토리얼 | 없음 (`초기 자금 a원` 지급) | 마이크 입력 확인 및 캐릭터 첫인상 파악 |
| **`1일차`** | 순수 기본 영업 (`계산` + `진열` + `휴식`) | **방해 효과 및 추가 미션 없음** | 코어 루프와 감정 게이지 속도에 온전히 적응 |
| **`2일차`** | 추가 미션 1종 해금 (`매장 청소` + 정산 시 `물품 발주`) | 바닥 오염 발생 시작 | 지시할 업무가 2종 → 3종으로 늘어나는 동선 분배 |
| **`3일차`** | 피크타임 손님 몰림 구간 등장 | 특정 시간대 손님 연속 입장 | 알바 단독 처리 한계 → 사장 직접 보조 타이밍 학습 |
| **`4일차`** | 외부 환경 방해 첫 등장 (`기상 악화: 폭우/태풍 등`) | 바닥 오염 가속 + 알바 피로 증가 | 청소·진열·계산 우선순위 판단 요구 |
| **`5일차`** | 손님 변수 등장 (`진상 손님 이벤트`) | 응대 시 알바 스트레스 급증 유발 | 알바 감정 폭발 방지(교대 응대 또는 직후 휴식·케어) |
| **`6일차`** | 복합 난이도 (`환경 변수 + 추가 미션 + 알바 이상행동`) | 높은 일일 고정비 및 바쁜 손님 유입 | 최종일 직전 자금 및 알바 충성도 최종 관리 |
| **`7일차`** | **최종 결전의 날 (최종 목표 금액 심사)** | 전 요소 복합 피크타임 | 7일 누적 목표 금액 완수 및 알바 최종 상태 결정 |

## 5. 최종 멀티 엔딩 분기 구조 (4대 엔딩)

| 엔딩 구분 | 발동 조건 | 매장(사장) 결말 | 알바 결말 · 후일담 톤 |
| :--- | :--- | :--- | :--- |
| **엔딩 1: 완벽한 동업 (진 엔딩)** | `7일차 목표 금액 달성` **+** `알바 상태 긍정` (`충성도 ≥ 70`, `스트레스 안정`) | 목표 금액 완수 성공! (사채 빚 전액 청산 & 참교육 / 우주 1짱 거상 등극) | 사장을 인정하며 정직원·장기 에이스 파트너로 남는 훈훈한 후일담 |
| **엔딩 2: 피도 눈물도 없는 흑자 (블랙코미디)** | `7일차 목표 금액 달성` **+** `알바 상태 부정` (`고스트레스` 또는 `충성도 저하·거부 누적`) | 돈은 다 벌어서 목표는 달성했으나 가게에 혼자 남음 | 마감 직후 번호 차단·당일 추노, 익명 게시판 폭로 또는 경쟁점 오픈 |
| **엔딩 3: 목표 미달 폐업 (재정 배드엔딩)** | `7일차 종료 시 목표 금액 미달` *(또는 중도 파산)* | 기한 내 목표 금액을 채우지 못해 점포 회수·폐업 엔딩 | 밀린 일당만 겨우 챙겨 씁쓸하게 떠나는 현실 후일담 |
| **엔딩 4: 알바 멘탈 폭주 (중도 배드엔딩)** | 영업 중 `스트레스 100(폭주)` 장기 방치 **+** `충성도 바닥` 도달 | 알바가 앞치마를 던지고 매장을 박차고 나가 영업 강제 중단·실패 | 실시간 탈주 및 신고로 수금일 전 가게가 마비되는 파국 엔딩 |

## 6. 기본 스토리 후보 2안 — 기승전결 스토리텔링 및 인게임 진행 설명

팀원들이 각 스토리가 실제 게임 진행(`0~7일차`)과 어떻게 맞물리는지 직관적으로 이해할 수 있도록 **기·승·전·결 서사**와 **인게임 플레이 방식**을 매칭해 정리한다.

---

### 후보 1안: 「밑바닥 빚쟁이 사장의 7일 생존 편의점」 (현실 블랙코미디)

> **한 줄 요약**: 사업 실패로 사채 빚을 진 주인공이 후미진 골목 편의점을 인수해, **7일 안에 사채 상환 목표액을 맞춰야 하는** 현실 밀착형 블랙코미디.

#### [기(起) — 도입 & `0~1일차`: 사채 차용증과 첫 알바 채용]
- **스토리 라인**:
  - 투자 실패로 알거지가 된 주인공. 사채업자에게 마지막 기회를 얻는 조건으로 폐업 직전의 동네 편의점을 인수한다.
  - 사채업자의 조건은 단 하나: ***"정확히 7일 뒤 자정에 수금하러 온다. 목표 금액 못 맞추면 가게고 인생이고 끝인 줄 알아라."*** (메인 로비에서 주인공이 편의점 앞에 쭈그려 앉아 한숨 섞인 담배 연기를 뿜고 있는 이유).
  - 주인공은 스트레스성 지병과 부상으로 혼자 매장을 다 뛸 수 없어, 남은 초기 자금(`a원`)으로 급하게 알바생 1명을 채용한다.
- **인게임 진행 방식**:
  - **`0일차`**: 클립보드(이력서)에서 알바의 이름·성격·말투를 설정하고, 마이크로 `"계산대 봐줘"`, `"진열대 채워줘"`를 지시하는 법을 리허설한다.
  - **`1일차`**: 방해 효과 없이 평범한 동네 손님들이 방문한다. 손님이 물건을 사 가면 비는 매대를 채우도록 지시하고, 카운터 계산을 분배하며 첫날 영수증 정산과 알바 스트레스 관리의 기본을 익힌다.

#### [승(承) — 전개 & `2~4일차`: 이자 독촉과 동네 편의점의 일상 변수]
- **스토리 라인**:
  - 장사가 조금씩 굴러가자 사채업자가 매일 밤 문자로 압박 수위를 높이고, 매장에는 비 오는 날 진흙 발자국과 재고 부족 같은 현실적인 골칫거리가 생겨난다.
  - 알바생도 피로가 쌓이기 시작해, 사장이 반말로 재촉하거나 하던 일을 중간에 자꾸 바꾸면 한숨을 쉬며 불만을 드러낸다.
- **인게임 진행 방식**:
  - **`2~3일차 (추가 미션 & 피크타임)`**: 손님들이 흘린 쓰레기를 치우는 **`바닥 청소`** 명령이 추가되고, 정산 클립보드에서 보유 자금으로 **`내일 물품 발주`**와 **`알바 야식/보너스 케어`**를 진행한다.
  - **`4일차 (기상 악화 방해 효과)`**: **폭우·태풍**이 몰아쳐 매장 바닥이 평소보다 2배 빨리 더러워지고 특정 물품(우산·컵라면) 재고가 빠르게 소진된다. 알바 혼자 손이 모자랄 때 사장이 직접 포스기로 달려가 계산을 보조해야 한다.

#### [전(轉) — 위기/절정 & `5~7일차`: 진상 손님, 알바 멘탈 임계점, 최후의 주말 영업]
- **스토리 라인**:
  - 수금일이 코앞으로 다가온 `5~6일차`, 동네 **진상 손님(환불 시비·술주정·반말)**이 들이닥쳐 알바생의 멘탈을 흔든다.
  - 스트레스가 `80(분노)`을 넘긴 알바는 *"사장님, 저도 손이 두 개거든요? 못 가요!"*라며 지시를 정면 거부하거나 물건을 떨어뜨리는 실수를 저지른다. 여기서 폭언·강제 지시를 계속하면 알바가 앞치마를 던지고 추노(`엔딩 4`)해버린다.
  - 대망의 `7일차`, 사채업자가 가게 밖에서 지켜보는 가운데 주말 최대 손님 러시가 쏟아진다.
- **인게임 진행 방식**:
  - 진상 손님 등장 시 사장이 직접 계산을 맡아 알바를 보호하거나, 정중한 음성 지시(`"고생했어, 잠깐 쉬어"`)로 스트레스를 낮추며 위기를 넘긴다.
  - `7일차` 마지막 제한 시간까지 알바와 사장이 총력전을 펼쳐 최종 목표 금액을 돌파한다.

#### [결(結) — 결말 & `4대 멀티 엔딩`: 자정 12시, 사채업자와의 결판]
- **엔딩 1 (`목표 달성 + 알바 긍정`)**: 사채업자 면전에 현금 다발을 던져 빚을 전액 갚고 불법 추심 증거로 통쾌하게 참교육 성공! 알바생도 사장을 믿고 든든한 점장(에이스 파트너)으로 남는다.
- **엔딩 2 (`목표 달성 + 알바 부정`)**: 빚은 다 갚아 가게는 지켰지만, 혹사당한 알바는 정산금을 받자마자 번호를 차단하고 알바 익명 게시판에 *『사채업자보다 더 악독한 사장 후기.txt』*를 올려 인기글 1위를 달성한다.
- **엔딩 3 (`목표 미달 폐업`)**: 돈을 다 못 모아 점포를 뺏기고, 주인공은 씁쓸하게 야간열차를 타며 도망간다 *(과격한 '묻힘' 대신 블랙코미디 톤 연출)*.
- **엔딩 4 (`알바 폭주 중도 종료`)**: 영업 중 알바가 실시간 탈주하고 노동청에 진정서를 넣어 수금일이 오기도 전에 영업이 강제 종료된다.

### 후보 2안: 「은하계 변방, 지구 물품 수출 만물상」 (SF 병맛 코미디)

> **한 줄 요약**: 먼 미래 우주 산업 시대, 외계 행성 환승 정거장에 '지구 물품 전용 만물 편의점'을 차린 주인공이 **7일 안에 은하 독점 무역권 보증금(목표 금액)을 모으는** SF 병맛 코미디.

#### [기(起) — 도입 & `0~1일차`: 우주 정거장 가건물 오픈과 지구인 알바 채용]
- **스토리 라인**:
  - 지구 물건이 우주에서 비싸게 팔린다는 소문을 듣고, 전 재산을 털어 외계인 환승 정거장에 '지구 만물 편의점'을 가오픈한 주인공.
  - 하지만 은하 상공회의소의 정식 허가 심사일까지 남은 기간은 **단 7일**! 그 안에 목표 보증금을 못 내면 점포는 강제 철거되고 우주 정거장 노숙자로 전락한다.
  - 주인공은 우주 멀미(중력 부적응) 때문에 오래 움직일 수 없어, 초기 자금(`a원`)으로 지구인(또는 로봇/외계 혼혈) 알바생 1명을 고용해 장사를 시작한다.
- **인게임 진행 방식**:
  - **`0일차`**: 클립보드에서 알바 페르소나를 설정하고 음성 명령을 테스트한다.
  - **`1일차`**: 온순한 외계인 관광객들이 찾아와 지구 과자·생필품을 사 간다. 기본 `계산`과 `진열` 지시만으로 우주 화폐 매출을 올리는 기본 루프를 익힌다.

#### [승(承) — 전개 & `2~4일차`: 병맛 지구 물품(총기 등) 입고와 우주 환경 재해]
- **스토리 라인**:
  - 가게가 소문나면서 외계 용병과 보따리상들이 몰려들고, 파는 물건도 컵라면 옆에 **'지구산 소총', '플라즈마 건전지', '고양이 통조림'** 같은 기상천외한 병맛 물품으로 확장된다.
  - 외계 손님들이 바닥에 흘리고 가는 외계 점액질과 우주 환경 이상 현상이 매장 운영을 방해하기 시작한다.
- **인게임 진행 방식**:
  - **`2~3일차 (추가 미션 & 특수 발주)`**: 외계 점액질을 닦는 **`바닥 청소`** 미션이 해금되고, 정산 클립보드에서 지구 화물선으로 **`특수 물품(무기/희귀품) 발주`** 및 **`알바 멘탈 케어(지구 특식 보너스)`**를 진행한다.
  - **`4일차 (우주 기상 악화)`**: 폭우 대신 **'우주 자기장 폭풍 / 소행성 파편 충돌 / 인공중력 흔들림'**이 발생해 매장이 빠르게 어질러지고 알바의 피로도가 급상승한다.

#### [전(轉) — 위기/절정 & `5~7일차`: 외계 진상 손님, 무기 파손 실수, 은하 무역선 피크타임]
- **스토리 라인**:
  - `5~6일차`에는 지구 문화를 모르는 **외계 진상 손님(촉수로 매대 어지럽히기, 매장에서 총기 시험 발사 요구)**이 나타나 알바의 스트레스를 폭발시킨다.
  - 스트레스가 임계점(`80+`)에 도달한 알바는 지시를 거부하거나 고가의 지구 무기를 떨어뜨려 파손 손실을 낸다. 방치하면 알바가 비상 탈출 포드를 타고 지구로 추노(`엔딩 4`)해버린다.
  - `7일차` 마지막 날, 대형 은하 무역선단이 정박하며 외계 손님들이 구름처럼 몰려든다.
- **인게임 진행 방식**:
  - 외계 진상 손님은 사장이 직접 포스기에서 빠르게 계산해 내보내거나, 알바에게 제때 휴식을 지시해 폭주를 막아야 한다.
  - `7일차` 총력전에서 알바와 호흡을 맞춰 독점 무역권 보증금 목표치를 달성한다.

#### [결(結) — 결말 & `4대 멀티 엔딩`: 우주 무역 1짱 vs 정거장 노숙자]
- **엔딩 1 (`목표 달성 + 알바 긍정`)**: 정식 독점 무역권을 따내며 은하계 무역 1짱 거상으로 등극! 알바생은 '지구 무역 제1지점장'으로 승진해 함께 우주를 제패한다.
- **엔딩 2 (`목표 달성 + 알바 부정`)**: 우주 1짱 거상은 되었으나, 혹사당한 알바생이 퇴직금을 들고 바로 맞은편에 **'원조 지구 만물상'**을 차려 사장의 외계 단골들을 싹 쓸어간다.
- **엔딩 3 (`목표 미달 노숙자`)**: 보증금을 못 채워 점포가 압류되고, 주인공은 우주 정거장 벤치에서 은박지 담요를 덮고 자는 우주 노숙자가 된다.
- **엔딩 4 (`알바 폭주 중도 종료`)**: 분노한 알바가 유일한 지구 귀환 캡슐을 타고 혼자 도망쳐버려, 성난 외계 손님들 한가운데에 사장 혼자 남겨진 채 가게가 망한다.
