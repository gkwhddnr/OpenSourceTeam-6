## 1. 문서 목적 및 개발 단계 구분

본 문서는 게임 최초 실행부터 `0일차(오픈 준비)` → `1~7일차(영업·정산 반복)` → `최종 멀티 엔딩`까지 이어지는 **본편 전체 게임 흐름**과 **스토리·에셋 방향성 후보**를 팀원 전체가 동일한 그림으로 공유하기 위해 작성되었다.

구현 일정 혼선을 막기 위해 **1차 통합 데모(현재 마일스톤)**와 **2차 본편 확장 범위**를 아래와 같이 구분한다.

| 구분 | 1차 통합 데모 (단일 일차 코어 검증) | 2차 본편 완전체 (전체 게임 흐름) |
| :--- | :--- | :--- |
| **진행 일차** | 로비 → `1일차` 즉시 진입 (`120초` 시연 기준) | 인트로 → 로비 → `0일차(설정·튜토리얼)` → `1~7일차` 누적 루프 |
| **알바 설정** | 기본 대표 프리셋(`김민수`) 1명 고정 | `0일차`에 프리셋 선택 / 이름·성향 직접 설정 / 랜덤 생성 지원 |
| **손님 · 매출** | 시간 × 감정 효율 비례 가상 매출 (`직원 외 NPC 보류` 규칙 준수) | 손님 NPC 입장 → 물품 선택 → 알바(건수 누적)/사장 직접 계산 → 퇴장 |
| **방해 · 미션** | 없음 (계산·진열·휴식 및 감정 반응 검증 집중) | 일차별 기상 악화·진상 이벤트·알바 이상행동·청소·발주 미션 점진 추가 |
| **정산 · 소비** | 1단 정산 결과창 (매출·원가·고정비·3등급 확인) | 3단 정산 루프: ①매출·인건비 결산 → ②알바 상태 리포트 → ③자금 소비(발주·케어) |
| **엔딩 구성** | 1일차 운영 3등급 (및 2단 후일담 프로토타입) | 7일차 최종 4대 멀티 엔딩(목표×알바 상태) + 중도 파산·알바 폭주 엔딩 |

## 2. 전체 게임 진행 흐름도 (End-to-End Flow)

```text
[게임 최초 실행]
   └──▶ [인트로 연출] (세계관 도입 영상 또는 스토리 텍스트 / 클릭·Esc 스킵 지원)
            │
            ▼
      [메인 로비 화면]
       ├─ [게임 시작] ──▶ (새 게임 시) [0일차: 오픈 준비 단계]
       │                     ├─ ① 알바 채용 및 페르소나 설정 (프리셋 / 직접 입력 / 랜덤)
       │                     ├─ ② 기본 조작 및 음성 지시 튜토리얼 (스킵 가능)
       │                     └─ ③ 초기 운영 자금(a원) 지급 ──▶ [1일차 오픈 전환 컷신]
       ├─ [설정] ──────▶ [환경 설정 창] (볼륨 · 마이크 장치 · 마우스 감도 조절)
       └─ [종료] ──────▶ 게임 종료
                                    │
                                    ▼
  ┌─────────────────── [Day 1 ~ Day 7 일차 반복 루프] ───────────────────┐
  │                                                                      │
  │  1. [인게임 영업 (1인칭 시점)]                                       │
  │     - 상단 HUD: 현재 일차 · 남은 시간 · 보유 금액 / 목표 금액 표시   │
  │     - 손님 입장 및 상품 선택 → 알바 음성 지시(또는 사장 비상 계산)   │
  │     - 일차별 방해 효과(기상·진상·알바 이상행동) 및 추가 미션(청소 등)│
  │     - Esc 입력 시: [일시정지 메뉴] (계속하기 / 설정 / 로비로 이동)   │
  │                                                                      │
  │  2. [영업 종료 트리거]                                               │
  │     - 제한 시간 만료(00:00) 또는 플레이어의 [조기 마감] 선택         │
  │     - (예외: 영업 중 알바 멘탈 완전 폭주 시 → 중도 배드엔딩 직행)    │
  │                                                                      │
  │  3. [일차 정산 및 정비 (클릭/버튼 3단 전환)]                         │
  │     - [화면 1] 정산 연출 & 오늘 매출·지출(알바 수당 등)·목표 달성도  │
  │     - [화면 2] 오늘 알바 상태 리포트 (스트레스·충성도·감정 한마디)   │
  │     - [화면 3] 정비 시간 자금 소비 (재고 발주 · 알바 케어)           │
  │        └─ Day 1~6 종료 시: 다음 일차(x+1일차) 오픈으로 이동 ─────────┘
  │        └─ Day 7 종료 (또는 중도 파산) 시: 최종 엔딩 판정으로 이동
  ▼
[최종 엔딩 컷신 및 알바 후일담 출력] ──▶ [메인 로비 복귀]
```

## 3. 단계별 상세 규칙 (자연스러운 연결 및 꼼수 방지 보완)

### 3.1 인트로 · 로비 · 설정/일시정지 조작 구분
1. **인트로**: 최초 실행(또는 새 게임 시작) 시 짧은 텍스트·컷신으로 왜 이 매장을 운영해야 하는지(목표 금액과 기한)를 전달하며, 반복 테스트 편의를 위해 **`[스킵]` 버튼(`Space`/`Esc`)**을 상시 제공한다.
2. **설정 vs 인게임 `Esc` 구분**:
   - **로비에서 `[설정]` 클릭 시**: 곧바로 `환경 설정 창` 출력.
   - **인게임 중 `Esc` 입력 시**: 게임 타이머를 멈추는 **`[일시정지 메뉴]`**(`계속하기` / `설정` / `메인 로비로`)를 먼저 띄우고, 그 안의 `[설정]`을 누르면 환경 설정 창이 열리도록 구성한다. *(보조 텍스트 명령창 등이 열려 있을 때는 열린 팝업을 먼저 닫음)*

### 3.2 `0일차` (알바 설정 · 튜토리얼 · 초기 자금 지급)
1. **알바 페르소나 설정**: 정식 오픈 전 함께 일할 알바의 `이름`, `성격 성향`, `말투 스타일`을 설정한다 (원클릭 프리셋 3종 / 직접 입력 / 범위 내 랜덤 지원). 공정한 난이도를 위해 **허용 업무 종류와 정산 단가는 모든 페르소나가 동일**하게 유지한다.
2. **오픈 리허설(튜토리얼)**: 마이크 입력 키와 `Tab` 보조 텍스트 창으로 알바에게 계산·진열·휴식을 한 번씩 지시해 보는 짧은 실습 단계다. 이미 익숙한 플레이어는 즉시 건너뛰고 1일차로 넘어갈 수 있다.
3. **초기 자금(`a원`) 지급**: 매장 인수 직후 기본 운영 자금 `a원`(예: `50,000원`)이 지급되며, 이 자금은 각 일차 종료 후 정비 단계(`x일차`와 `x+1일차` 사이)에서 물품 발주나 알바 케어 비용으로 사용할 수 있다.

### 3.3 인게임 영업: 손님 응대 · 음성 지시 · 사장 직접 개입 규칙
1. **음성 명령 및 말투 영향**:
   - 플레이어는 마이크로 알바에게 업무(`계산`, `진열`, `청소`, `휴식` 등)를 지시한다.
   - 같은 업무라도 **업무 중 강제 전환 여부**와 **플레이어의 발화 말투(정중한 부탁 vs 재촉·폭언)**에 따라 알바의 스트레스·충성도 증감 폭이 달라진다.
2. **손님 NPC 흐름 및 계산 주체별 차등 규칙 (본편 핵심 트레이드오프)**:
   - 손님 NPC가 매장에 입장해 확률에 따라 구매할 물품을 고르고 카운터로 온다 *(해당 매대 재고가 비어 있으면 구매하지 않고 이탈하여 매출 기회 손실 발생)*.
   - 계산 완료 시 손님 NPC가 퇴장하며, **누가 계산했느냐**에 따라 비용과 감정이 다르게 반영된다.

| 계산 주체 | 재화(정산) 처리 | 알바 감정 · 게임플레이 영향 (밸런스 안전장치) |
| :--- | :--- | :--- |
| **알바 NPC가 계산** | 내부에서 **처리 횟수(또는 유효 수행 시간)**를 저장했다가, 일차 정산 시 **기본급 + 건당 인센티브(수당)**로 일괄 지불 | 정상 업무 루프. 연속 근무 시 스트레스·피로도가 서서히 상승하므로 적절한 휴식 배분 필요 |
| **플레이어(사장)가 직접 계산** | 알바 건당 수당 미발생 (인건비 절약) | **꼼수 방지 페널티 부여**: ① 사장의 포스기 조작 속도가 알바보다 느려 계산 대기열·매장 관리가 밀림. ② 알바가 멀쩡한(`안정`) 상태인데 사장이 계속 카운터를 독점하면 성실형 알바는 *"날 못 믿나?"*(충성도 하락·눈치 스트레스 상승), 게으른 알바는 버릇이 나빠져 태업 확률 상승. 단, **알바가 과부하·분노 상태일 때 사장이 급한 손님을 대신 쳐주면** 알바의 부담이 줄어듦 |

> **설계 의도**: 플레이어가 인건비를 아끼려고 알바를 방치한 채 혼자 다 계산하는 플레이(음성 지시 게임 정체성 붕괴)를 막고, **"평소엔 음성 지시로 알바를 굴리되 바쁜 피크타임이나 알바 멘탈 관리 시에만 사장이 직접 손을 보태는 운영 게임"**이 되도록 유도한다.

3. **영업 종료 및 임의 조기 마감 규칙**:
   - 영업 제한 시간이 모두 소진되면 즉시 영업을 마감한다.
   - 플레이어는 포스기/출입문 마감 기능으로 **시간이 남았어도 임의로 일차를 조기 종료**할 수 있다. 단, 악용 및 오조작 방지를 위해 다음 제약을 둔다:
     1. 최소 영업 경과 시간(예: `30초`) 이후 및 확인 팝업을 거쳐 실행 가능.
     2. **돌발 방해 이벤트(진상·사고 등) 발생 중에는 수습하기 전까지 조기 마감 불가.**
     3. 조기 마감하더라도 **당일 고정 운영비(임대료·기본 일급)는 전액 차감**된다. (목표 매출을 일찍 달성했거나 알바 폭주 직전에 손절할 때 쓰는 전략적 판단 요소)

### 3.4 일차 마감 3단 정산 및 정비 루프 (`x일차 → x+1일차`)
일차가 끝나면 마감 연출과 함께 클릭/버튼 상호작용으로 아래 3단계를 순서대로 거친다.

1. **[1단계] 당일 매출 및 지출 정산 화면**:
   - `당일 총매출` - `총지출(상품 원가 + 고정 운영비 + 알바 기본급·계산 건수 수당 + 실수/파손 손실)`을 합산하여 **최종 보유 금액**과 **목표 금액 달성 진행도**를 표시한다.
   - *(보유 금액이 감당 불가능한 적자/파산 기준선 아래로 떨어지면 중도 파산 엔딩으로 분기 가능)*
2. **[2단계] 알바 상태 결산 화면**:
   - 오늘 하루 누적된 알바의 `스트레스 지수`, `피로도`, `충성도`, `현재 감정 상태(안정/불만/분노)`, `지시 거부 횟수`와 퇴근 직전 속마음 한 줄 대사를 출력한다.
3. **[3단계] 오픈 전 정비 · 자금 소비 화면 (`Day 1~6` 종료 시)**:
   - 보유 금액을 소비해 **다음 날 판매할 물품 발주(재고 보충)** 또는 **알바 멘탈 케어(야식·보너스 지급 → 스트레스 감소 및 충성도 회복)**를 선택한 뒤 다음 일차(`x+1일차`)로 넘어간다.

## 4. `0일차 ~ 7일차` 난이도 곡선 및 방해·미션 구성

메모 초안의 방해 효과와 추가 미션을 개발 구현 단위에 맞춰 **3가지 카테고리**로 명확히 분리하고 일차별로 점진 배치한다.

### 4.1 변수 및 미션 3대 분류
- **① 알바 이상행동 (내부 감정 변수)**: 스트레스 누적·성향에 따라 발생하는 **태업(농땡이), 물건 떨어뜨림, 계산 실수, 정면 지시 거부**.
- **② 외부 방해 효과 (환경·손님 변수)**:
  - **기상 변화**: 폭우·태풍 등 (매장 바닥 오염 속도 증가, 우산/특정 물품 수요 급증 등).
  - **까다로운 손님(진상 이벤트)**: 계산 지연 유발, 알바 스트레스 급상승 유발 (빠른 중재 또는 휴식 케어 필요).
- **③ 추가 운영 미션**: 기본 `계산·진열` 외에 새로 해금되는 **바닥 청소, 긴급 재고 발주, 유통기한 폐기 정리** 등.

### 4.2 일차별 권장 진행 구성표
| 일차 | 핵심 목표 및 해금 요소 | 방해 효과 · 추가 미션 | 난이도 의도 |
| :---: | :--- | :--- | :--- |
| **`0일차`** | 알바 페르소나 설정 + 음성/텍스트 지시 튜토리얼 | 없음 (`초기 자금 a원` 지급) | 마이크 입력 확인 및 캐릭터 첫인상 파악 |
| **`1일차`** | 순수 기본 영업 (`계산` + `진열` + `휴식`) | **방해 효과 및 추가 미션 없음** | 코어 루프와 감정 게이지 속도에 온전히 적응 |
| **`2일차`** | 추가 미션 1종 해금 (`매장 청소` + 정산 시 `물품 발주`) | 바닥 오염 발생 시작 | 지시할 업무가 2종 → 3종으로 늘어나는 동선 분배 |
| **`3일차`** | 피크타임 손님 몰림 구간 등장 | 특정 시간대 손님 연속 입장 | 알바 단독 처리 한계 → 사장 직접 보조 타이밍 학습 |
| **`4일차`** | 외부 환경 방해 첫 등장 (`기상 악화: 폭우/태풍`) | 비 오는 날 바닥 오염 가속 + 알바 피로 증가 | 청소·진열·계산 우선순위 판단 요구 |
| **`5일차`** | 손님 변수 등장 (`진상 손님 이벤트`) | 응대 시 알바 스트레스 급증 유발 | 알바 감정 폭발 방지(교대 응대 또는 직후 휴식·케어) |
| **`6일차`** | 복합 난이도 (`기상 변수 + 추가 미션 복합`) | 높은 일일 고정비 및 바쁜 손님 유입 | 최종일 직전 자금 및 알바 충성도 최종 관리 |
| **`7일차`** | **최종 결전의 날 (최종 목표 금액 심사)** | 전 요소 복합 피크타임 | 7일 누적 목표 금액 완수 및 알바 최종 상태 결정 |

## 5. 최종 멀티 엔딩 분기 구조

`7일차` 정산 완료 시점의 **① 최종 목표 금액 완수 여부**와 **② 알바의 누적 상태(충성도·스트레스·거부 이력)** 조합, 그리고 **중도 실패 조건**을 합쳐 총 **4대 엔딩 분기**로 명확히 정의한다. *(연출 제작 공수에 따라 기본 엔딩 컷신 + 알바 상태별 후일담 카드 결합 방식, 또는 조건별 독립 컷신 방식으로 구현 가능)*

| 엔딩 구분 | 발동 조건 | 매장(사장) 결말 | 알바 결말 · 후일담 톤 |
| :--- | :--- | :--- | :--- |
| **엔딩 1: 완벽한 동업 (진 엔딩)** | `7일차 목표 금액 달성` **+** `알바 상태 긍정` (`충성도 ≥ 70`, `스트레스 안정`) | 목표 금액 완수 성공! (사채 빚 전액 청산 성공 / 우주 무역 1짱 등극) | 사장을 진심으로 인정하며 정직원·장기 에이스 파트너로 남는 훈훈한 후일담 |
| **엔딩 2: 피도 눈물도 없는 흑자 (블랙코미디)** | `7일차 목표 금액 달성` **+** `알바 상태 부정` (`고스트레스` 또는 `충성도 저하·거부 누적`) | 돈은 다 벌어서 목표는 달성했으나 가게에 혼자 남음 | 마감 직후 번호 차단·당일 추노, 익명 게시판 사장 폭로글 인기글 등극 |
| **엔딩 3: 목표 미달 폐업 (재정 배드엔딩)** | `7일차 종료 시 목표 금액 미달` *(또는 중도 파산)* | 기한 내 목표 금액을 채우지 못해 점포 회수·폐업 엔딩 | 밀린 일당만 겨우 챙겨 씁쓸하게 다른 알바 자리를 알아보는 현실 후일담 |
| **엔딩 4: 알바 멘탈 폭주 (중도 배드엔딩)** | 영업 중 `스트레스 100(폭주)` 장기 방치 **+** `충성도 바닥` 도달 | 알바가 앞치마를 던지고 매장을 박차고 나가 영업 강제 중단·실패 | 노동청 민원 접수 및 동네 소문으로 구인 불가 상태가 되는 파국 엔딩 |

## 6. 기본 스토리 · 세계관 후보 비교 (팀 확정 안건)

**스토리가 먼저 확정되어야 매장 3D 에셋, 판매 물품, 손님 외형, 음성 인식 단어장 방향이 결정된다.** 현재 아래 두 가지 후보를 두고 팀 합의로 최종 확정한다.

| 비교 항목 | 후보 1안: 「인생 역전 빚쟁이 편의점」 (현실 블랙코미디) | 후보 2안: 「우주 수출 만물 편의점」 (SF 병맛 코미디) |
| :--- | :--- | :--- |
| **배경 및 도입** | 사업 실패 후 사채 빚을 내어 동네 편의점을 인수. 7일 안에 목표 상환액을 맞춰야 함 | 먼 미래 우주 산업 시대, 외계인들에게 지구 물품(생필품~총기 등 기상천외한 물건)을 파는 무역 편의점 |
| **성공 / 실패 결말** | **성공**: 빚 전액 상환 + 사채업자 통쾌한 역관광(참교육)<br>**실패**: 점포 압류 및 웃픈 야반도주/노역 엔딩 *(과도하게 잔인한 표현 대신 블랙코미디 수위 유지)* | **성공**: 은하계 무역왕(우주 1짱 거상) 등극<br>**실패**: 우주 정거장 빈털터리 노숙자 전락 |
| **에셋 수급 · 제작** | **매우 유리** — 무료 현대 편의점·인간 캐릭터 에셋이 풍부하며 직관적임 | **개성 강함 (직접 디자인 유리)** — 단순하거나 기묘한 형태의 직접 제작 모델도 '외계 컨셉'으로 자연스럽게 소화 가능 |
| **Whisper 음성 인식** | **최상** — `계산대`, `진열대`, `청소`, `삼각김밥` 등 한국어 일상 어휘라 인식률이 매우 안정적임 | **주의 필요** — 생소한 외계 단어는 오인식 위험이 있으므로, **업무 지시 키워드 자체는 쉬운 한국어(`계산`, `진열`, `무기 칸 채워`)로 고정** 필수 |
| **유머 · 인디 매력** | 현실 알바·자영업자 공감형 웃픈 블랙코미디 | 스트리머·시연 발표 시 시선을 확 끄는 비주얼 병맛 요소 |

> **공통 아키텍처 원칙**: 1안과 2안 중 무엇을 선택하더라도 **코드 레벨의 핵심 시스템(`음성 의도 판별 → 감정 변화 → 이동 → 일차 정산 → 7일 루프`)은 100% 동일하게 동작**하도록 구현하며, 에셋·대사 테이블·아이템 명칭만 세계관에 맞춰 입힌다.

## 7. 담당자별 확인 및 논의 요청 사항

1. **공통 결정 안건**: 위 **6장의 스토리 후보(1안 현실 편의점 vs 2안 우주 만물상)** 중 이번 프로젝트의 비주얼·에셋 방향으로 어느 쪽을 채택할지 결정.
2. **이승재 (`음성·AI`) 참고**: `0일차`에서 설정한 페르소나 프로필이 `1~7일차` LLM/감정 가중치에 이어지며, 음성 발화 태도(정중/재촉/폭언)와 일차별 알바 이상행동 해금 구조를 단계적으로 연결.
3. **하종욱 (`카메라·이동`) 참고**: 1차 데모 완료 후 본편 확장 시 플레이어의 포스기 직접 계산 상호작용(`Raycast`/근접 상호작용) 및 손님 NPC 입·퇴장 동선(`NavMesh`) 확장 여부 검토.
4. **송재명 (`기획·UI·정산·스토리`) 진행**: 1차 데모 UI 기반 위에 `인트로` · `0일차 페르소나/튜토리얼` · `3단 정산/정비 UI` · `4대 멀티 엔딩 화면` 순차 확장.
