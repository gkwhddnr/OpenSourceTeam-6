# 직원 음성 명령 데모

1. `Scenes/EmployeeVoiceDemo.unity`를 연다.
2. Hierarchy에서 `Employee Voice Demo`를 선택한다.
3. Inspector에 이 폴더의 `Assets/ggml-small-q5_1.bin`과 `Assets/qwen2.5-1.5b-instruct-q4_k_m.gguf` 경로가 설정되어 있다. 다른 모델을 쓰려면 절대 경로 또는 프로젝트 루트 기준 상대 경로로 변경한다.
4. Play 후 Game 화면에서 `Record command`를 눌러 말하고 `Stop recording`을 누른다. 녹음 최대 길이에 도달하면 자동으로 종료된다. 텍스트를 입력하고 `Send text command`로 판단 기능만 확인할 수도 있다.
5. Console에서 `[EmployeeVoice] Recognized`, `Intent`, `action` 메시지를 확인한다. Inspector에서 직원 이름, 성격, 스트레스, 피로도, 충성도를 조절할 수 있다.

## 명령과 직원 상태

지원 업무는 주문받기, 음식 제공, 테이블 청소, 쓰레기 버리기, 재고 보충이다. 명령 해석은 LLM이 담당하고 명시적인 업무·대상 단어를 별도로 확인한다. 부정, 복합 지시 또는 확인되지 않은 표현은 추측하지 않고 재설명을 요청한다. 예를 들어 `3번 테이블 치워`는 청소로 처리하고 `저것 좀 해`는 재설명을 요청한다. 이 단어 기반 검사는 보수적이므로 의미가 분명한 다른 표현도 재설명을 요청할 수 있다.

테이블 정리 명령은 요청 업무와 직원 행동을 분리한다. `3번 테이블 치워`는 `CLEAN_TABLE` 요청과 대상 `3`으로 해석하되, 직원 행동은 `CLEAN_TABLE`, `THROW_AWAY_TABLE`, `IGNORE_COMMAND`, `COMPLAIN`, `REST` 중 하나로 선택한다. 테이블 번호가 명시되지 않으면 대상으로 `unspecified`를 기록하며 추측하지 않는다.

LLM은 직원의 성격·상태를 보고 다섯 후보 중 하나를 제안하고, 제안의 가중치에 1.25배를 적용한다. 최종 선택은 성실함(`diligence`), 문자 그대로 받아들이는 정도(`literalness`), 게으름(`laziness`), 스트레스·피로·충성도를 반영한 가중 무작위 방식이다. 이 값들은 Inspector의 Personality에서 0~100으로 조절한다. 실수나 감정 행동이 매번 일어나거나 특정 성격에 절대적으로 고정되지는 않는다. 수치는 플레이 테스트를 위한 초기값이며 향후 조정이 필요하다. LLM이 후보 밖 결과를 반환하거나 판단에 실패하면 실행하지 않고 재시도를 요청한다.

다른 네 업무는 기존 임시 상태 규칙을 유지하며, 실제 오브젝트 이동이나 실수 연출은 하지 않는다. 판단 결과와 분류는 Console에만 출력된다. 동일한 명령과 상태라도 가중 무작위 선택으로 결과가 달라질 수 있다.

음성 인식 및 명령 해석 시간은 Console의 `elapsed_ms`에 밀리초로 출력한다. `managed_bytes`는 .NET 관리 메모리, `unity_allocated_bytes`는 Unity 관리 할당량의 스냅샷이다. 전체 프로세스 메모리 또는 GPU 메모리를 의미하지 않는다.

## 플레이어 배포용 모델 경로

모델을 빌드에 자동으로 동봉하거나 자동 다운로드하지 않는다. Windows 플레이어 실행 시 `Application.persistentDataPath/EmployeeVoiceModels/`에 아래 파일을 별도로 제공한다. 실제 경로는 회사·제품명 설정에 따라 달라지며, 파일이 없으면 Console에서 필요한 전체 경로를 확인할 수 있다.

- `ggml-small-q5_1.bin`
- `qwen2.5-1.5b-instruct-q4_k_m.gguf`

에디터에서는 씬의 프로젝트 상대 경로를 사용하고 플레이어에서는 위 폴더의 동일한 파일명을 사용한다. 이 경로 처리는 구현됐지만 플레이어 빌드와 다른 PC에서의 모델 전달·구동은 아직 확인하지 않았다. LLMUnity의 네이티브 라이브러리 포함 여부와 플랫폼별 마이크 권한도 배포 빌드에서 검증해야 한다. 모델 및 라이브러리 고지 준비 내용은 `THIRD_PARTY_NOTICES.md`를 확인한다.

현재 행동은 Console 출력까지만 구현되어 있으며 직원 모델은 플레이 중 생성되는 임시 캡슐이다. 모델이 로딩 중이거나 파일, 마이크, LLM을 사용할 수 없으면 상태 메시지를 표시한다.
